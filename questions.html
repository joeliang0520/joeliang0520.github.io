Current focus

Spatial memory for egocentric assistants

Assistants on AI glasses see the user's surroundings and hear what the user says, but conversational memory usually keeps only the dialogue. In SpaC-MEM, we reconstruct objects in 3D from RGB video and attach each turn of the conversation to the objects it mentions, so the assistant can answer questions such as "Where did Dana leave her mug?" We also release the Ego-SpaCR benchmark (620 video sessions, 3,100 questions). [PDF] [arXiv] [Code]
